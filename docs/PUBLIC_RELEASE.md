# 公开版本说明

更新于 2026 年 10 月 25 日。公开版用于自行部署与功能演示，默认名称为“校园墙”。

## 公开范围

保留业务源码、前端镜像、依赖锁文件、运行脚本、测试、配置样例和项目文档。许可文件、作者归属、贡献说明与独立演示入口一并保留。

公开文件不包含真实学校名称、学校地址、原站点品牌或公众号名称、非公开仓库链接、专属二维码与头像、用户数据、环境配置、密钥、上传目录、日志及本机材料。站点地址和联系邮箱使用示例值，故事列表为空，自动连载默认关闭。

页面标题、SEO 元数据、AI 提示词、邮件模板和公众号内容均使用通用文案。`frontend/favicon.svg` 为通用站点图标；二维码指向示例地址。部署时替换为自己的站点信息和资源。

天气位置使用 `WEATHER_CITY`、`WEATHER_LATITUDE`、`WEATHER_LONGITUDE` 配置。未设置城市与有效坐标时，首页显示天气暂不可用，不请求原站点所在位置的天气；公众号天气也不使用默认城市。

部署脚本必须显式配置 `DEPLOY_REPO_URL`。公开上传与生产部署分别执行，不会由源码上传触发生产服务器更新。

## 文档与演示

README 提供项目概览、实际页面截图、快速启动、开发命令与文档导航。截图来自内置演示，使用示例数据。

演示通过浏览器本地数据实现帖子、评论、点歌、私信和审核，不连接生产数据库、不执行邮件或公众号草稿发送。构建与发布见 [演示说明](PAGES_DEMO.md)。

## 自动检查

`npm run check:privacy` 扫描已跟踪文件中的明显凭据、学校标识、非公开仓库链接及已知专属图片。诊断只输出文件、行号和类别，不回显原内容。

`npm run test:public-privacy` 在临时仓库中验证拦截行为：通用文案与协议兼容字段通过，学校标识和仓库链接失败。`X-Gitee-Token` 是部署协议兼容字段，不是仓库地址。
