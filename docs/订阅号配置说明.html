订阅号配置说明

本文只记录当前源码支持的配置和流程。Token、AES Key、Secret、JWT 密钥等真实值只能放在服务器私有环境变量中，不能写入仓库、日志或截图。

一、服务器回调

微信公众平台的服务器地址使用：

https://你的域名/api/wechat/callback

回调由 routes/wechat.js 处理 GET 验证和 POST 消息。签名校验默认要求时间戳在最近 5 分钟内；可通过 WECHAT_SIGNATURE_TTL_SECONDS 调整，消息体上限由 WECHAT_BODY_LIMIT_BYTES 控制。

在服务器私有配置中填写以下变量，值从微信公众平台获取：

WECHAT_TOKEN=请填入公众号服务器配置中的Token
WECHAT_ENCODING_AES_KEY=请填入公众号服务器配置中的EncodingAESKey
WECHAT_APPID=请填入公众号AppID
WECHAT_SECRET=请填入公众号AppSecret

WECHAT_TOKEN 用于签名，启用安全模式或兼容模式时还需要 WECHAT_ENCODING_AES_KEY。WECHAT_SECRET 用于公众号接口调用和 access token 获取；未配置时相关服务不会启动。

二、当前支持的订阅号能力

  • 接收关注、取消关注、文本、图片、语音、位置和链接消息。
  • 通过固定公众号二维码完成关注，再在对话中发送绑定码；不依赖带参数二维码。
  • 模板消息发送函数保留兼容接口，但订阅号不支持模板消息，当前不会实际发送。

三、网站绑定流程

  1. 用户登录个人中心，点击“绑定微信”。
  2. 网站调用 POST /api/wechat/generate-bind，返回一次性绑定码和固定二维码 /images/gzh.jpg。
  3. 用户扫码关注公众号后，在对话中发送页面显示的绑定码。
  4. 页面调用 POST /api/wechat/verify-follow 检查绑定状态；已绑定账号可通过 POST /api/wechat/unbind 解除绑定。

绑定状态查询使用 GET /api/wechat/status。绑定码和关注记录有有效期，页面提示失效后重新生成即可。

四、上线前检查

  1. 确认服务器使用 HTTPS，回调路径可从公网访问。
  2. 确认私有环境变量已加载，真实值未出现在 Git 差异、日志和前端资源中。
  3. 在微信公众平台提交服务器配置，检查 GET 验证返回微信提供的 echostr。
  4. 用测试账号验证关注、发送绑定码、状态查询和解除绑定。
